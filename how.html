How

Tape Floor is a desk, not a signal shop. Three different things live here:

  • watch — names on the board. Looking. Not a ticket.
  • ticket — paper work we track. Still not a call to you.
  • call — we almost never make public calls. If we do, it says so out loud.

Lanes we use when something moves past watch:

  • GAMBLE — small, fast, easy to be wrong.
  • BUILD — thesis with room to add if it holds.
  • HOLD — already in; manage, don’t chase.

Paper first. Live size is human — a person clicks, not a bot.
